CMYK Screen Separator 0.2.0-beta / Windows 11
GIMPを使う、写真のシルクスクリーン用CMYK網点4色分解ツール

【ダウンロード版の使い方】
1. ZIPをフォルダーへすべて展開します。ZIPの中から直接起動しないでください。
2. GIMP 3をインストールしてください。Pythonの追加インストールは不要です。
   公式配布元：https://www.gimp.org/downloads/
3. 「起動.cmd」または「Start.cmd」をダブルクリックします。
   既存の通常版GIMP 3を自動検出します。
   Store版のみの場合、初回は利用者のインストールから作業用コピーを作ります。
   その場合、数百MB（目安700MB）の空き容量と初回準備時間が必要です。
   管理者権限やWindowsのセキュリティ設定変更は行いません。

【写真を見ながら選ぶ】
「画像を選ぶ」を押すと、フォルダー内のJPEG・PNGがサムネイルで並びます。
写真をクリックすると右側に拡大プレビューと画像名・寸法を表示します。
「この写真を使う」で確定します。フォルダーはダブルクリックで移動できます。
破損画像は確定できません。写真のアップロードは行いません。

【分解後に保存先を決める】
「分解が終わってから保存先を選ぶ」が初期状態でオンです。
1. 用紙・画像比率・余白または切り抜き・DPIを設定します。
2. ピクセル寸法と配置プレビューを確認し「4色分解して書き出す」を押します。
3. 分解後に表示される画面で、保存先のフォルダーを選びます。
4. 画像名と日時を付けた新規サブフォルダーに4枚を保存します。
   C.JPEG、M.JPEG、Y.JPEG、K.JPEG
保存先選択を「後で保存」で閉じても分解済みデータを保持します。
「保存先を選んで保存」から再開でき、アプリを閉じても次回起動時に復元します。
保存失敗時も保持するので、別の保存先へ再試行できます。
最初から保存先を決めたい場合はチェックを外してください。
既存のファイルは上書きしません。元の写真も変更しません。

【出力条件】
JPEG全体の寸法は指定した幅・高さ（mm）です。
ピクセル数は mm / 25.4 × DPI を四捨五入します。
画像比率を指定した場合はまず中央で比率を整え、次に用紙全体へ配置します。
画像の縦横比を保って拡大縮小します（整数ピクセルへの丸めがあります）。
GIMP内でサイズ・切り抜き・余白を適用してからCMYK分解を行います。
各色に階調の反転1回、新聞印刷：白地に黒・円形・周期7 px・45°・品質1を適用。
品質1はアンチエイリアスのオーバーサンプリング係数1です。
網点化後のリサイズはせず、別の1レイヤー画像としてJPEG品質100%で保存します。
4枚の寸法・DPI情報・グレースケールを保存前に検査します。

【保存されるデータ】
保存先には4枚のJPEGと、設定・検査結果・処理ログを保存します。
アプリのdataフォルダーは専用設定・未保存の作業データ用です。
未保存の版があるときはdataを削除しないでください。
配布ZIPにはdata、GIMP本体、個人の写真、検証中の処理ログを含めていません。

【対応・制限】
Windows 11 / GIMP 3。GIMP 3.2.8で実機検証しています。
各辺30000 px・合計4億画素以内。高解像度では十分なメモリが必要です。
GIMP標準CMYK分解を使用し、印刷所用ICCプロファイルの指定機能はありません。
JPEGは非可逆圧縮のため、網点境界に中間階調が生じる場合があります。
本ソフトはベータ版です。GIMPの手作業4版との完全一致比較と実印刷試験は未完了です。
GIMP公式の製品ではありません。

【GIMPが見つからない場合】
通常版GIMP 3を公式サイトからインストールして再起動してください。
独自の場所へインストールした場合は、環境変数CMYK_GIMP_ROOTに
binフォルダーを含むGIMPのインストール先を指定できます。
Start.cmd --check で検出先、Start.cmd --console で起動時のログを確認できます。
