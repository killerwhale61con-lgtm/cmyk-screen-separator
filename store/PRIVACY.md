# プライバシーポリシー（Microsoft Store版・公開前の案）

対象：CMYK網点4色分解 / CMYK Screen Separator

本アプリは選択した写真を利用者のPC上のGIMPで処理します。写真、分解した版、ファイル名を開発者のサーバーへ送信する機能、広告、利用状況の解析機能はありません。GIMPは別途インストールする外部アプリです。

画像は読み取り専用で開きます。処理用データ、4枚の版、設定、処理ログは利用者のローカルアプリデータ内に保存します。ログやjob.jsonには元画像のファイルパスが含まれる場合があります。保存保留時は再開できるように4枚を保持します。指定された保存先には新規フォルダーを作成します。入力写真は上書きしません。

サポートのためログや画像を公開する場合は、利用者が内容を確認してください。GitHubの公開Issueへ写真や個人情報を添付する必要はありません。

Microsoft Store、Windows、別途インストールしたGIMPのデータの扱いは、それぞれの提供者のポリシーに従います。
